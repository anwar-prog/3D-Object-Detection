# 3D-Object-Detection
This project features a real-time system designed to identify the maturity levels of manufacturing components using a 2D camera and a Convolutional Neural Network (CNN) based on the VGG Imagenet architecture. The primary goal of the system is to enhance productivity, minimize errors, and improve overall efficiency in manufacturing processes.

# Key Features:

Data Collection: Utilizes a diverse dataset comprising real-time images and synthetic 3D-CAD data to ensure accurate and representative classification across various manufacturing stages.

Data Augmentation: Implements techniques such as rotation and scaling to increase dataset variability and enhance model robustness against real-world conditions.

CNN Architecture: Integrating the VGG Imagenet algorithm and leveraging transfer learning for improved performance and efficiency.

Real-Time Deployment: Optimizes the system for real-time operation with limited resources, ensuring reliable performance under varying lighting conditions and partial views.

# ABSTRACT

This paper focuses on developing a robust system for identifying the maturity levels of diverse manufacturing components. The system aims to improve productivity, reduce errors, and increase overall efficiency by utilizing a 2D camera and VGG Imagenet-based Convolutional Neural Network (CNN). The dataset consists of real-time images and synthetic 3D-CAD data, which is strategically collected to ensure representativeness and diversity, crucial for accurate classification across various manufacturing stages. Data augmentation techniques, including rotation and scaling, increase dataset heterogeneity and make the model robust against real-world variations. To be able to deploy the system in real time with limited resources, the project explores several CNN architectures while considering model complexity and computational efficiency into account. It focuses particular attention on the integration of the VGG Imagenet algorithm. Additionally, transfer learning plays a crucial role, as it leverages pre-trained knowledge from the VGG Net. Rigorous testing and validation using images of real production ensures that CNN performs under realistic conditions, including variations in lighting and field orientation. To ensure the model’s reliability in practical scenarios, its ability to manage blind spots and partial views is evaluated. The developed system provides valuable insights into manufacturing processes after successful completion, enables data-driven decisions, and facilitates real-time operations. The system empowers manufacturers to implement targeted process improvements, reduce errors, and improve overall efficiency. The project contributes to the advancement of manufacturing systems but also highlights the incorporation of the VGG Imagenet algorithm, laying the groundwork for future innovations across material handling, process control, and overall manufacturing performance.
